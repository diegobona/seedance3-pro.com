# 游客图片试用

GPT Image 2 和 GPT Image 2.5 共用总计 2 张免费图片额度，无需注册和登录。默认每次生成 1 张，也可一次生成 2 张；失败退还本次预扣额度。额度不会每日刷新。H3 的 10 秒游客视频额度独立赠送，图片和视频互不扣减。登录后新请求沿用账户每天 15 积分的规则。

新增 D1 迁移 `0004_guest_image_trial.sql`。每个图片游客使用独立的 `plan=guest` 非登录身份，初始 10 内部积分，每张消耗 5 分，两个图片模型共用同一身份。复用现有原子预扣、结算和幂等退款触发器，不修改注册账户余额或视频额度。

身份保存在 `seedance_guest_image` 签名 HttpOnly / Secure / SameSite=Lax Cookie 中，签名域和网络 HMAC 均独立于视频。网络 HMAC 唯一约束防止删除 Cookie 后重复领额度；共享公网 IP 共用初始资格，丢失 Cookie 无法恢复剩余额度。仅信任 Cloudflare 客户端 IP，不记录原始 IP。Cookie 不构成 Better Auth 会话。

`GET /api/credits/balance?guest_image=1` 预览或读取图片余额，不创建身份。返回 `remainingImages` 方便显示张数，内部 `remaining` 仍以积分计。图片响应用 `x-seedance-credit-scope=guest-image` 隔离账户和视频事件。游客一次最多 2 张，后端仍以实际请求张数原子预扣；供应商必须返回相同数量的有效图片才结算。

测试使用真实 Miniflare D1 和替代供应商，覆盖两个模型共享消费、两张批量、余额不足和并发超额拒绝、失败与重复退款、跨天不刷新、Cookie 签名与视频隔离、注册用户三张批量、非法参数和跨站请求、双语页面和前端余额上下文。测试不调用付费图片模型。

“让这张图动起来”验证当前登录身份或签名游客图片身份的源图归属，再将参考图交给当前账户或独立的视频游客身份。转交不消耗图片张数或视频秒数，视频仅在真正提交生成时预扣；中途登录仍可转交本浏览器游客生成的源图。未通过归属校验不会认领视频游客资格。

上线顺序为先在 `seedance3-production` 应用仅新增表的 0004，再发布 Worker。保留 Better Auth 密钥和 D1 配置；不访问 Neon。
