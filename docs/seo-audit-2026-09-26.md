# 站内 SEO 收尾检查 — 2026-09-26

本轮检查线上 sitemap 的全部 35 个页面，并核对 9 个旧地址、工作区或不参与收录的页面。修复保存在本地，尚未部署。

## 线上检查结果与本地修复

| 项目 | 发现 | 本地处理 |
| --- | --- | --- |
| 状态与规范地址 | 35 个 sitemap 页面均返回 200，canonical 与最终 URL 一致 | 保持现有地址 |
| 标题与 H1 | 没有重复标题，所有页面各有一个 H1；一篇历史文章标题过长 | 精简 Seedance 2.0 模板文章标题，同步 H1、社交标题和 Blog 卡片 |
| 页面描述 | 两篇提示词文章仍使用同一句 CMS 默认描述 | 按实际内容分别撰写描述，同步社交描述、页面导语及 Blog 摘要 |
| 图片 alt | 三模型比较文章的三张信息图未提供 alt | 根据图中实际内容补充说明；装饰图及已有相邻文字的缩略图保留空 alt |
| 孤立页面 | `/minimax-h3-vs-seedance-3` 没有来自这批页面的内链 | 在 Blog 的工作流入口中加入比较文章链接 |
| 失效锚点 | Features、FAQ 指向首页不存在的 `#generator`；比较页指向不存在的 `#status` | 前两处改为 H3 生成器；后一处改为现有 `#models` 并同步链接文字 |
| 旧模型页重复入口 | `/gpt-image-2` 和 `/minimax-h3-ai-video-generator` 仍返回可索引的旧页面 | 扩展现有 308 跳转映射，增加裸域与 www 的 Worker 路由和资源优先处理配置；旧静态文件设为 noindex，canonical 指向正式工具页 |
| 非收录页面 | 通用工作区、Seedance 2.5 工作区、预留提示词库、Prompt Guide、Pricing、Nano Banana 页面均为 noindex | 保持现有策略 |

## 验证

- 51 项相关自动检查通过，包含旧模型地址映射与 Cloudflare 路由覆盖检查。
- `npm run build` 通过，包含 TypeScript 检查。
- 对更新后的本地静态 HTML 与本轮抓取的未修改动态页面进行组合校验：35 个页面标题、描述各自唯一；均有一个 H1、正确 canonical 和索引指令；图片均带 alt；指向这批页面的锚点有效。
- 从首页沿 HTML 文本链接遍历，可以到达全部 35 个 sitemap 页面。
- 本轮没有进行媒体播放、API 生成、外站链接或历史文章事实数据的全面审查。未使用 GSC 数据，因此不判断实际收录、曝光或排名。

## 部署

需要同时发布静态页面和 Worker（包括 `wrangler.jsonc`）。部署后应重点复核两个旧模型无后缀地址是否返回 308，并落到对应 `/app/...` 工具页。

Worker 路由配置依据：[Cloudflare Routes 文档](https://developers.cloudflare.com/workers/configuration/routing/routes/)。
