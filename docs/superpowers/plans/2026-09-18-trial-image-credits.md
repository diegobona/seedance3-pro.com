# Trial Image Credits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every newly registered user 15 one-time trial credits and charge 5 credits for each successful GPT Image 2 generation, with atomic balance protection and automatic refunds for failed generations.

**Architecture:** Keep the existing Better Auth `user.creditBalance` as the authoritative spendable balance. Add a small `generation_credit_reservation` table so every provider attempt has a unique reservation state; database CTEs atomically reserve or refund credits and prevent concurrent overspending/double refunds. Expose authenticated balance data through a first-party API and return the remaining balance with generation responses so the studio can stay synchronized.

**Tech Stack:** TanStack Start, Better Auth, React, Drizzle ORM, Neon PostgreSQL, Cloudflare Workers, Node test runner.
