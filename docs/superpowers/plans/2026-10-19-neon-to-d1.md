# Neon to Cloudflare D1 implementation plan

> Execute with parallel agents, local runtime tests, and independent review before any data switch.

**Goal:** Move the deployed application's eight relational tables to D1 while preserving accounts, sessions, credits, video jobs and referral statistics.

**Architecture:** Keep the current PostgreSQL driver available during preparation and rollback. Add a D1 binding, SQLite auth schema and dedicated D1 stores; route database selection through one environment factory. Use atomic D1 batches and accounting triggers for conditional credit reservations and terminal transitions. Preserve the existing R2 activity gate.

**Data safety:** The source currently rejects even SELECT 1 because compute quota is exhausted. No source backup exists. Do not switch production to an empty D1 database or initialize an empty source export. Prepare and test everything that is independent of source access. The eventual cutover requires restored source read access, consistent export, verified import and a freeze of old writers. Never print account/password/session values or connection secrets.
