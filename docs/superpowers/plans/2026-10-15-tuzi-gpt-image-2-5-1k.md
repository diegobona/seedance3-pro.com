# Tuzi GPT Image 2.5 Integration Plan

**Goal:** Add Tuzi's `gpt-image-2.5-1k` image route as an independently selectable, authenticated image generator in both languages.

**Architecture:** Keep the same-origin `/api/images/generate` endpoint, existing Tuzi secret, aggregate rate limit and credit reservation/refund pipeline. Use the website ID `gpt-image-2-5-1k`, mapped explicitly to provider ID `gpt-image-2.5-1k`. Share an allowlisted model/size configuration between client and server. Preserve old clients' GPT Image 2 default and all existing Christmas changes. Maintain the existing trial policy of five credits per image. Provider prices vary by token group and are not website retail prices.

**Verified source:** https://api.tu-zi.com/pricing?vendor=OpenAI&model=gpt-image-2.5-1k says the model name is a Tuzi routing alias, supports generation/editing and requires its published fixed size set. The 1:1 size is 1254x1254; other shapes follow the provider table. Do not present existing GPT Image 2 images as results generated by this model.
