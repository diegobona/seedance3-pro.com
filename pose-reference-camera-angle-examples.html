Pose reference case study

3D pose references.
Six camera views compared.

A crossed-arms stance, a kneeling pose, and a jogging pose—each captured from two camera views. Compare the reference with its first image output, using the same character prompt throughout.

By SEEDANCE 3.0 · September 22, 2026

Crossed armsKneelingJoggingMethod & promptLimitations

The camera changes what an image reference shows: which limbs overlap, how much of the body is visible, and the space around the figure. This comparison looks at pose, visible anatomy, and framing separately instead of treating them as one result.

The references come from the single-mannequin editor currently online in Seedance Pose Studio. Outputs use the site's existing developer API adapter with the provider model requested as gpt-image-2. These are API examples using live-editor references, not six generation transactions through the production workbench. Read the full method and prompt.

How to read the panels: each case labels the original mannequin reference and its first output. Images keep their original aspect ratios. Open either image to inspect the original file.

Behind the comparison

The method, settings, and full prompt

This study uses three presets from the live single-mannequin editor. Within each pair, the body pose stays unchanged while the camera is adjusted manually. View labels describe the intended composition; they are not measured camera angles. Capture and zoom details belong to each reference's evidence record.

The six references are submitted individually through the site's existing developer API adapter. Each reference gets one initial request and one first output, with the same prompt and settings. The protocol retains weak results, makes no automatic paid retries, and does not retouch the output images.

The same prompt for all six references

The first paragraph is the live editor's automatic pose-reference instruction. The second supplies the shared character and visual direction. No camera-specific instruction is added between cases.

Use the attached 3D mannequin only as a body-pose and camera-angle reference. Preserve the pose and framing; do not copy the mannequin's appearance.

Create a realistic studio photograph of one adult woman with a short black bob, a mustard-yellow jacket, charcoal trousers, and white sneakers. Use a plain light-gray studio background and soft, even lighting. Follow the attached reference for body pose, camera angle, and framing.

Reading the evaluations

Pose, visible anatomy, and framing use separate descriptive 0–2 scales. They summarize these images only. An occluded feature that cannot be assessed must be called out, rather than silently treated as correct.

All six first requests returned PNG images. The originals are linked without retouching or resizing. Although the requested size was 1024 × 1024, every delivered PNG measures 1254 × 1254. No zoom adjustments were made between captures; camera orbit was manual.

What this comparison can and cannot tell you

These six examples are an exploratory look at camera composition. They are not a scientific benchmark, a success rate, or evidence that a camera angle alone caused an output change. Only one output is requested per reference, and no seed is fixed.

The reference captures are wider than square, while the requested outputs are 1024 × 1024. That aspect-ratio change can affect crop, subject scale, and empty space. Manual orbit and unfixed generation randomness also limit direct comparisons; inspect each source image rather than assuming a measured camera setup.

A matching outfit does not demonstrate identity preservation. A plausible silhouette does not establish correct hidden anatomy. No example guarantees an exact joint match, and this study does not test multiple figures, other image models, or pose-to-video generation.

Practical observations from these six outputs

In these six outputs, the main stance and broad view generally follow the mannequin. Exact hand placement and subject scale do not. Use the reference to make the silhouette and view readable, then inspect hands, feet, overlaps, and crop separately. The low-view crossed-arms example is a useful reminder to review a convincing image against the actual reference.
