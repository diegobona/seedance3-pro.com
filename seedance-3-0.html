A practical reading order

  1. Check the version and source. Start with the release timeline. Keep earlier-version announcements separate from claims about 3.0.
  2. Write one clear shot. Pick a prompt template, replace the subject and setting, then describe one main action and a camera move. Keep it as a draft until the model's input format is confirmed.
  3. Prepare a reference and review checklist. Use the AI pose generator to explore framing. Record which pose, lighting and composition details you want to preserve, then verify that your chosen tool accepts the material.
