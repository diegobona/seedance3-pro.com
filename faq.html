Frequently Asked Questions

This page is designed as both a user help section and an SEO-targeted FAQ landing page for deployment and product usage queries.

Can I use generated videos for commercial projects?

Yes. Paid plans include commercial usage rights for ads, social campaigns, and brand content production.

What file formats are supported?

The front-end supports common image, video, and audio formats. You can extend validation rules when backend APIs are connected.

Is Cloudflare deployment straightforward?

Yes. The current implementation is fully static and can be deployed through Cloudflare Pages with Git auto-deploy.

Do I need to start backend services now?

No. You can run the complete acquisition funnel with the static site first, then connect generation APIs under /api routes later.

How should I structure future SEO pages?

Keep a clear hierarchy: homepage, feature page, use-case pages, pricing page, and FAQ page. Expand each use-case into long-tail landing pages over time.
