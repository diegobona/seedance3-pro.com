# Website copy

- Describe the service through concrete facts. Do not claim that this website is official, and do not label it unofficial, independent, affiliated, or unaffiliated.
- Attribute external announcements and documentation to their actual publishers. Preserve source links and identify the model used by each generation tool accurately.
- Mark unconfirmed release timing as an estimate, for example “Expected January–February 2027” / “预计 2027 年 1–2 月发布”. Never present an estimate as an announced release date.
- Keep visible text, page titles, descriptions, structured data, FAQs, translation catalogs, and generated content consistent with these rules.
