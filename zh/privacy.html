2. 我们处理的信息

注册前的游客试用：为管理免费额度和防范滥用，我们会记录游客标识、试用用量，以及由 IP 地址生成的非直接识别网络标识。我们也会根据浏览器提供的系统、显卡、屏幕、处理器、时区和字体特征，生成用于辅助判断的设备指纹。特征在浏览器内经过哈希处理，服务端保存再次加密处理后的标识，用于防范跨浏览器或更换网络后重复领取。我们不会接收原始特征，也不会通过设备指纹授予账户或生成内容的访问权限。配置相近的设备可能被识别为相同设备，隐私设置也可能使识别失效。带签名的游客试用 Cookie 最长可保留 1 年。注册或登录时，游客用量可能与账户关联，以核对免费额度。

  • 账户与登录信息：姓名、邮箱、头像、登录服务方标识与令牌，以及登录会话。Google 登录为可选方式。会话记录可能包括 IP 地址和浏览器或设备的 User-Agent 信息。
  • 生成信息：提示词、上传的参考图、所选模型与生成参数、任务编号与状态、结果链接，以及相关用量或错误信息。其中部分信息会发送给生成服务商，并非全部作为完整提示词历史保存在我们的任务数据库中。
  • 积分与购买信息：积分余额与变动、订单与支付编号、金额、币种、支付状态，以及退款或争议记录。
  • 访问与来源信息：随机访客标识、访问标识、入口页面路径、访问来源与时间，用于来源归因和了解用户如何访问服务。

3. 信息用途

我们使用这些信息完成登录、处理生成请求、展示和核对积分、验证付款、排查失败与争议、回复客服请求、防范滥用，以及了解访问来源。

请仅提交你有权使用的信息，并避免上传生成所不需要的机密资料或敏感个人信息。

4. 服务商与信息共享

服务使用第三方基础设施与生成服务：

  • Cloudflare：提供网站和 API 基础设施，D1 用于账户与服务记录，R2 用于视频参考图等上传存储。
  • 生成服务商：图片请求经由 Tuzi 处理；视频请求根据所选流程使用 AutoDL 或 CompShare。为完成请求，我们会向相应服务商发送所需的提示词、参考图和生成参数。
  • Stripe：提供支付结账以及支付、退款和争议处理。支付信息在 Stripe 结账页面填写；我们使用支付编号与状态管理订单。
  • Google：当你选择 Google 登录时，Google 处理其身份验证环节，并提供完成登录所需的账户信息。

这些服务商按照各自的条款与隐私做法处理信息，其处理和保留方式可能与我们不同，也取决于使用的服务。数据库迁移前使用的 Neon 数据库中，也可能保留历史记录或备份。

客服请求所需信息也会通过客服邮箱处理。在适用法律要求，或处理欺诈、安全事件和支付争议时，我们可能提供相关记录。

5. Cookie 与浏览器存储

我们使用 Cookie 维持登录和语言偏好。访问来源追踪使用最长约 1 年的随机访客 Cookie，以及约 30 分钟的访问或来源 Cookie。

浏览器也会保存工作区运行所需的信息：IndexedDB 可在首页向工作区交接参考图时暂存图片；sessionStorage 可保存草稿与任务编号；localStorage 可用于在标签页之间传递登录状态事件。关闭标签页不代表所有本地数据都已清除。

你可以通过浏览器设置管理 Cookie 和网站存储。清除后可能需要重新登录，也可能移除本地草稿或参考图，或中断生成素材的交接。

6. 存储与保留时间

我们会为服务运行、客服、账务、反欺诈和争议处理保留必要的账户、积分、订单与服务记录。保留时间取决于记录类型和用途；目前并非所有数据都适用同一个自动删除期限。

上传的视频参考图链接通常在约 24 小时后无法访问。链接过期不代表文件已在同一时刻从存储中物理删除，实际清理可能延后。生成结果链接的可用时间也可能取决于服务商。

浏览器副本、服务商记录、历史数据库和备份可能有不同的保留时间。请自行保存需要长期保留的生成结果。
