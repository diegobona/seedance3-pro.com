Seedance 2.0 提示词模板与运镜指南

用分镜模板和运镜词典编写 Seedance 视频提示词，学习如何描述景别、动作、光线与转场。

你是否遇到过这种情况：输入“a girl walking down the street”，生成的视频却没有运镜，人物僵硬、转场生涩，看起来像低清晰度的 PowerPoint 演示？

问题往往不在工具本身，而在提示词缺少“结构”和“运镜”。结构决定视频是否耐看，运镜决定视觉表现。今天我们一起解决这两个核心问题—新手也能直接运用这些原则，制作更有专业感的视频！

  • 为什么随手写的提示词总是适得其反？

多数人的 AI 视频创作逻辑是：模糊的画面构想 → 自然语言描述 → AI 尝试理解，却十有八九无法达到预期。根源在于没有向 AI 明确说明运镜类型、镜头切换、光效和节奏相关的视觉效果。

行业创作者 @yanhua1010 直言：AI 视频质量的 70% 取决于运镜描述，而不是场景描述。

对比一下就能看出差别：

❌ 普通描述：A girl walking in the forest.

✅ 专业描述：A girl walking in the forest, Smooth Dolly Follow, golden hour lighting.

一个像监控画面，一个像电影—区别就在运镜！

  • 第一层：从零开始即可套用的通用结构模板

用户 @leslieyu0 发布了一套分镜式提示词模板，把视频各要素固定下来—复制后即可使用：

(Multi-shot sequences for dynamic character portrayal/high-impact action sequences with seamless shot transitions) [@Material 1] Serving as the primary reference frame, [Character Name] represents the protagonist.

Shot 1 ([Shot Type]): The character appears in [Scene], performs [Core Action], and is accompanied by [Local Effects]; Shot 2 ([Shot Type]): Smooth transition between shots, focusing on facial expressions to intensify emotions; Shot 3 (Optional): Briefly highlights supporting elements to reinforce the core action.

Includes overall [art style], color [lighting], and built-in [sound effects/music]. Duration: 5s.

不知道术语怎么写？把模板交给 ChatGPT 或 Kimi，说明风格、主角与氛围，让 AI 补全“快速推拉”“光子粒子流”“断层转场”等技术描述。

  • 第二层：运镜词典 – 填写模板时最关键的一项

模板中的“镜头类型”一栏，90% 的用户容易写错。以下是新手必须掌握的三层运镜词库。

1. 三个基础术语：一切运镜的基础

·Pan / Tilt（摇镜头）：机位保持不动，镜头水平或垂直转动，适合展示环境全貌。

·Zoom（变焦）：调整焦距，放大或缩小主体，突出细节。

·Dolly（移动镜头）：实际移动机位，跟随主体，形成身临其境的感觉。

⚠ 注意：Pan 是“站着不动转头”，Dolly 是“整个人跟着移动”。混用这些词会让指令含混。

2. 加上修饰词，让表现更进一步

在基础词汇上加上明确修饰，马上建立电影画面感： ✅ 速度：Smooth（平滑）、Slow（缓慢）、Fast（快速）、Subtle（轻微） ✅ 情绪：Cinematic（电影感、通用）、Dreamy（梦幻）、Aggressive（强烈）、Intimate（亲密） ✅ 风格：Handheld（手持）、Aerial（航拍）、Dutch Angle（倾斜构图）

组合示例：Smooth Dolly Forward、Slow Aerial Pan、Cinematic Handheld Tracking

3. 组合运镜：适配 Seedance 2.0

单一运镜已经可用，组合运镜能让画面更完整。但每段视频最多安排两种运镜—过多指令只会让画面混乱。

·Orbit + Zoom In（环绕＋推近）：适合人物登场与产品展示。

·Crane Up + Pan（升降＋摇镜头）：适合营造氛围的开场或结尾。

·Dolly Zoom（滑动变焦）：希区柯克式眩晕效果。

·Tracking + Handheld Shake（跟拍＋手持晃动）：适合动作与追逐场景。

⚠ 5 条避坑规则：来自反复实践

1.动作写得缓慢、有顺序：不要只写“跳舞”，而应描述“缓缓转身，轻轻抬手”。

2.运镜保持稳定、简单： ≤每段视频最多两种运镜组合

3.增加稳定约束：画面流畅稳定，不抖动、不闪烁。

4.人物约束必不可少：表情稳定、不变形，五官清晰，服装保持一致。

5.用精确描述替代模糊词：移动 → 平滑地向前移动镜头 3 秒；漂亮 → 治愈、清新、温暖的光线

  • 场景运镜速查表：新手可直接选用

·人像特写：Dolly In 缓慢推进，配合 Intimate 与 Smooth。

·风景展示：缓慢水平摇镜头，配合 Cinematic 与 Dreamy。

·动作跟拍：Tracking + Handheld，配合 Fast 与 Aggressive。

·产品展示：Orbit + Zoom 环绕推进，配合 Smooth 与 Subtle。

·开场镜头：Crane Up + Pan，配合电影感与慢动作。

·回忆或梦境：Dolly Zoom / Slow Pan，配合 Dreamy 与 Subtle。

·城市夜景：Aerial Crane Down 航拍下降，配合 Cyberpunk 与 Cinematic。

✨ 最后想说
